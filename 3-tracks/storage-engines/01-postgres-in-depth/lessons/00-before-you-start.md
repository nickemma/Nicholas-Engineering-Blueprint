# 00 Before you start

> Postgres in depth · Setup · Builds on Core 03 Docker and Postgres

Use Go 1.26.6 or later, Bash, Python 3, and Docker. The live gate brings its own PostgreSQL 17 server and clients. It creates a temporary container bound to loopback, force-stops that container during one test, and removes its data after the gate.

Create an empty learner directory from your Blueprint checkout.

~~~bash
go version
python3 --version
docker version
export blueprint="$PWD"
scratch=$(mktemp -d)
cd "$scratch"
~~~

Docker should report both client and server. Use the same scratch folder through the lessons. The lab uses synthetic queue data and a small set of recovery markers.

### Pin pgx for the transaction schedules

Put the experiments in a small Go module of their own.

Create `go.mod`.

<!-- file: go.mod -->
~~~text
module switchyard/pgdepth

go 1.26.6

require github.com/jackc/pgx/v5 v5.11.0

require (
	github.com/jackc/pgpassfile v1.0.0 // indirect
	github.com/jackc/pgservicefile v0.0.0-20240606120523-5a60cdf6a761 // indirect
	github.com/jackc/puddle/v2 v2.2.2 // indirect
	golang.org/x/sync v0.17.0 // indirect
	golang.org/x/text v0.29.0 // indirect
)
~~~
