# 05 Profile two equivalent read paths

> Distributed KV capstone · Week 2 · Builds on lesson 04

## The problem

The YCSB matrix shows what clients observed. It does not show how much CPU the Rust lookup itself consumed or which work changed.

## The mental model

Use the exact two reader functions from the projection process against one fixed fixture. Each fixture has overlapping SSTables, 75,000 lookups, and an equal number of hits and misses. Collect sampled stacks separately from unprofiled elapsed times.

## The pattern

The baseline merges a singleton range. The indexed path chooses candidate blocks using the existing point lookup. Both return the same record to the caller. Use actual CPU samples for the flame graphs and matched timing runs for relative cost.

## Build it

### Step 1 — Make the build comparable

Enable the pinned sampler only for profiles and leave debug symbols available for stack names.

fn profile(
    root: &Path,
    mode: &str,
    count: &str,
    destination: &str,
) -> Result<(), Box<dyn std::error::Error>> {
    use std::{fs::File, hint::black_box, time::Instant};

    let count: usize = count.parse()?;
    if count == 0 {
        return Err("operation count must be positive".into());
    }
    let path = ReadPath::parse(mode)?;
    let mut store = Store::open(root)?;
    for run in 0_u8..8 {
        for key in 0_u16..64 {
            store.put(&(key * 2).to_be_bytes(), &[run; 64])?;
        }
        store.flush()?;
    }
    let keys: Vec<_> = (0_u16..128).map(u16::to_be_bytes).collect();
    for key in &keys {
        black_box(path.lookup(&store, key)?);
    }
    let guard = if destination == "-" {
        None
    } else {
        Some(
            pprof::ProfilerGuardBuilder::default()
                .frequency(499)
                .blocklist(&["libc", "libgcc", "pthread", "vdso"])
                .build()?,
        )
    };
    let mut hits = 0;
    let start = Instant::now();
    for i in 0..count {
        let key = &keys[i.wrapping_mul(29) % keys.len()];
        hits += usize::from(path.lookup(black_box(&store), black_box(key))?.is_some());
    }
    let ns = start.elapsed().as_nanos();
    let samples = if let Some(guard) = guard {
        let report = guard.report().build()?;
        let samples = report.data.values().sum::<isize>();
        if samples <= 0 {
            return Err("profile collected no samples".into());
        }
        report.flamegraph(File::create(destination)?)?;
        samples
    } else {
        0
    };
    println!(
        "{{\"path\":\"{mode}\",\"operations\":{count},\"hits\":{hits},\"elapsed_ns\":{ns},\"samples\":{samples}}}"
    );
    Ok(())
}
