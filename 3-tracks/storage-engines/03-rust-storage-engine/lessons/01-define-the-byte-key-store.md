# 01 Define the byte-key store

> A Rust storage engine · Week 1 · Builds on lesson 00

## The problem

An empty value is a valid record. A deleted key must be absent. If both cases use empty bytes, a caller cannot tell whether a record exists.

## The mental model

Draw a sorted map from each byte key to a list of mutations. A put adds a version with a value. A delete adds a version with no value. The scan interval includes its start and excludes its end.

## The pattern

The in-memory table, or memtable, puts versions of one key in increasing sequence order. Byte keys sort lexicographically. The local sequence only describes the order in which this engine accepts mutations.

### Step 3 — Assign sequence numbers

Put, overwrite, and delete one key. Predict the three sequence numbers and what a read of the final version should return.

<details>
<summary>Hint</summary>

</details>

<details>
<summary>Implementation</summary>

Create `src/lib.rs`.

<!-- file: src/lib.rs -->
~~~rust
use std::collections::BTreeMap;

pub type Row = (Vec<u8>, Vec<u8>);

#[derive(Clone, Debug, Eq, PartialEq)]
struct Version {
    seq: u64,
    value: Option<Vec<u8>>,
}

#[derive(Default)]
pub struct Store {
    seq: u64,
    mem: BTreeMap<Vec<u8>, Vec<Version>>,
}

impl Store {
    pub fn sequence(&self) -> u64 {
        self.seq
    }

    pub fn put(&mut self, key: &[u8], value: &[u8]) -> u64 {
        self.change(key, Some(value.to_vec()))
    }

    pub fn delete(&mut self, key: &[u8]) -> u64 {
        self.change(key, None)
    }

    fn change(&mut self, key: &[u8], value: Option<Vec<u8>>) -> u64 {
        self.seq += 1;
        self.mem.entry(key.to_vec()).or_default().push(Version {
            seq: self.seq,
            value,
        });
        self.seq
    }

    pub fn get(&self, key: &[u8]) -> Option<&[u8]> {
        self.mem.get(key)?.last()?.value.as_deref()
    }

    pub fn scan(&self, start: &[u8], end: &[u8]) -> Vec<Row> {
        if start >= end {
            return Vec::new();
        }
        self.mem
            .range::<[u8], _>((
                std::ops::Bound::Included(start),
                std::ops::Bound::Excluded(end),
            ))
            .filter_map(|(key, versions)| Some((key.clone(), versions.last()?.value.clone()?)))
            .collect()
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn distinguish_empty_from_deleted() {
        let mut store = Store::default();
        let mut reference = BTreeMap::new();
        for (key, value) in [(b"b", b"2".as_slice()), (b"a", b""), (b"c", b"3")] {
            store.put(key, value);
            reference.insert(key.to_vec(), value.to_vec());
        }
        assert_eq!(store.get(b"a"), Some(b"".as_slice()));
        assert_eq!(store.delete(b"b"), 4);
        reference.remove(b"b".as_slice());
        assert_eq!(store.get(b"b"), None);
        let expected: Vec<_> = reference
            .range(b"a".to_vec()..b"c".to_vec())
            .map(|(k, v)| (k.clone(), v.clone()))
            .collect();
        assert_eq!(store.scan(b"a", b"c"), expected);
        assert!(store.scan(b"c", b"a").is_empty());
        println!("empty value stayed visible; deletion and exclusive upper bound removed b and c");
    }
}
~~~
