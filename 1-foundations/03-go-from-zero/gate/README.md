# Gate: Go from zero

## What it checks

Your folder is your Go module, with `./cmd/tasks` (lesson 08) and `./cmd/loganalyse` (lesson 11).

1. **`tasks`**, in a fresh folder, through a scripted session of separate runs: `list` on nothing, two `add`s, `done 1`, `list`, then `done 9` (exit 1), `done abc` and no command at all (exit 2), and a second list with `-file`. Every output must match exactly, and every failure must print a reason on standard error.
2. **`loganalyse` on a small log full of traps:** a line that isn't JSON, an empty line, a status of 42, a negative `ms`, two lines tied for slowest, and a valid line of 100 KB. The counts, the slowest line (the earlier of the tie), and the malformed line numbers must be right, and identical with `-workers 1`, `-workers 7` and the default.
3. **`loganalyse` on a million lines,** generated by the same rules as lesson 11's `gen.awk`, with the expected answer worked out by `awk`, independently of your code.
4. **Memory:** on that 62 MiB log, at most 64 MiB, measured with `/usr/bin/time`.
5. **`gofmt`, `go vet` and `go test -race`** are clean for the whole module.

## Run it

~~~bash
bash gate/run.sh ~/blueprint/gofromzero
~~~

It needs Go and GNU `time` (`sudo apt install -y time`; macOS has `/usr/bin/time` already), and takes about 10 seconds.

## A pass looks like

~~~text
PASS  tasks: add, list, done, -file, and exit codes 1 and 2, across separate runs
PASS  loganalyse: bad lines reported, a 100 KB line read, ties broken by line, same answer with 1, 7 and the default number of workers
PASS  loganalyse: a million lines counted correctly
PASS  loganalyse: at most 64 MiB of memory for a 62 MiB log (it used 11 MiB)
PASS  gofmt: every file formatted
PASS  go vet: no problems
PASS  go test -race: all tests pass, no data races
Gate passed: on to Foundations 04.
~~~

## A fail looks like

Reading the whole log into memory:

~~~text
FAIL  loganalyse: at most 64 MiB of memory
      it used 229412 KiB. Read the file line by line with bufio.Scanner instead of loading it whole.
~~~

No `scanner.Buffer`, so the 100 KB line stops the scanner:

~~~text
FAIL  loganalyse -workers 1 on a small log with traps
      want:
      ...
      got:
      loganalyse: line 7: bufio.Scanner: token too long
~~~

`tasks done 9` exiting 0:

~~~text
FAIL  tasks done 9
      want exit 1 and:
      
      got exit 0 and:
~~~

The gate was checked both ways: it passes on the lessons' code, and each of five broken versions fails on the check aimed at it. The runs are in [evidence/](../evidence/README.md).
